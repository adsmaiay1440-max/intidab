# نجم الانتداب — الرفع على GitHub Pages

1. في GitHub (نفس حساب adsmaiay1440-max) اعمل مستودع جديد Public باسم: najm-intidab
2. ارفع كل الملفات دي في جذر المستودع (Add file ← Upload files).
3. Settings ← Pages ← Deploy from a branch ← main / (root) ← Save.
4. الرابط: https://adsmaiay1440-max.github.io/najm-intidab/

## المزامنة (Firebase)
- مربوط بنفس مشروع Firebase حق تطبيق الحسابات (om-fawaz)، ووثائقه تبدأ بـ NJM- فما تختلط مع بيانات الحسابات.
- لازم يكون المستودع على نفس الحساب adsmaiay1440-max عشان الدومين مسموح في Firebase مسبقاً.
- زر «مزامنة بين الأجهزة» ← إنشاء رمز ← أدخل نفس الرمز في الجهاز الثاني.

## عند أي تحديث للملفات
غيّر رقم النسخة في sw.js (najm-intidab-v3 ← v4) عشان يوصل التحديث للجوال فوراً.
